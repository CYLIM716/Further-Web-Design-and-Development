# Project Features & Technical Implementations ⚡

This prototype is the web-based digital component of an educational phygital game centered around a physical **Roulette Wheel**. It assesses student proficiency in Python programming concepts, fully complying with the core evaluation standards of the **APU CT117-3-2-FWDD** assignment:

### 🎡 Phygital Game Mechanics
*   **Roulette Integration:** Connects physical gameplay with the digital interface. Players spin a physical roulette wheel, land on a segment, and scan its embedded **QR Code** to launch corresponding challenges.
*   **Node.js Backend & API:** Powered by a Node.js server with a well-defined API that handles instant communication between player actions and the game server.
*   **Real-time Multiplayer Experience:** Supports multiplayer functionality, tracking scores and updating a real-time digital scoreboard for live competition.

### 🔒 Security & Data Persistence
*   **SQL Database Connectivity:** Integrated with a relational SQL data persistence system to perform complete CRUD operations (adding users, saving progress, retrieving question banks).
*   **User Recognition & Auth:** Incorporates standard security mechanisms for user registration and secure login, preserving game sessions for future visits.
*   **Form Input Validation:** Enforces strict front-end and back-end data validation rules to secure user input and maintain database integrity.

### 🧠 Gamified UX & Assessment
*   **Formative Python Assessments:** Delivers interactive quiz mechanics and knowledge tests targeted at specific Python concepts, providing instant feedback and state updates upon submission.
*   **Dynamic UI Architecture:** Features responsive layouts built on modern UI/UX design principles to ensure a fluid experience across phones, tablets, and laptops.
